TrapTrace AI

An On-Device Cross-Channel Cyberattack Detection and Reconstruction System

Project Overview

TrapTrace AI is an edge-based cybersecurity system designed to detect and correlate cyber threats across multiple communication channels.

It aims to identify suspicious SMS messages, phishing URLs, and malicious network activities locally without depending on cloud services.

Key Objectives

- Detect scam SMS messages.
- Identify phishing and suspicious URLs.
- Monitor and classify network traffic.
- Correlate security events across different channels.
- Reconstruct potential multi-stage cyberattack timelines.
- Explain detected threats and recommend defensive actions using an on-device Llama model.

Technology Stack

- Python
- Machine Learning
- Natural Language Processing
- Scapy
- SQLite
- Streamlit
- ExecuTorch
- Llama Family Models
- Raspberry Pi 5 / ARM64

Development Status

Phase 1 – Project foundation and event correlation.

Project Principle

All detection and analysis should prioritize local processing, user privacy, and evidence-based threat explanations.
